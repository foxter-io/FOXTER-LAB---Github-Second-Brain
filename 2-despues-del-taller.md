# Después del taller y si te atascas

Este archivo es para ti, no para Claude. Tiene los hábitos para la semana siguiente y las soluciones a los problemas más frecuentes.

---

## Después del taller

El valor está en el hábito. Con 10 minutos al día basta.

**Cada día (5–10 min):** al terminar una reunión o una tarea importante, pídele a Claude que guarde lo esencial en tu Second Brain, con el mismo filtro de cinco preguntas que usasteis en el taller. **Cada semana:** haz commit y push desde GitHub Desktop y pulsa **Sync now** en el Proyecto del móvil.

**Tareas recurrentes.** Para no repetir aquí lo que ya está escrito con detalle en otros archivos, esta tabla te dice qué pedir y dónde está la versión completa. Las frases funcionan cuando has instalado los skills y las rutinas (10 minutos cada uno).

| Quiero… | Dile a Claude | Versión completa |
|---|---|---|
| Revisar la salud del Second Brain (15 min, viernes) | "Ejecuta la rutina semanal" | Rutina 2 en `4-rutinas-mantenimiento.md` |
| Limpiar y actualizar las reglas (30 min, cada mes) | "Mantenimiento mensual" | Rutina 4 en `4-rutinas-mantenimiento.md` |
| Preparar una reunión | "Tengo una reunión con [PERSONA / CLIENTE] sobre [TEMA], prepárame" | Skill `preparar-reunion` en `3-skills-second-brain.md` |
| Escribir un correo con mi tono | "Contesta a este correo: [PEGA]" | Skill `redactar-en-mi-tono` en `3-skills-second-brain.md` |
| Afinar mi tono de voz | "Esta es la versión que envié: [PEGA]. Compárala con tu borrador y propón qué actualizar en tone-of-voice.md" | Skill `redactar-en-mi-tono`, paso 9 |

**Redactar un correo con tu tono (sin skills):**

```text
Usa tone-of-voice.md para redactar un correo a [PERSONA / ROL] sobre [TEMA]. Objetivo: [QUÉ QUIERO CONSEGUIR]. Dame solo el borrador.
```

**Cerrar un proyecto:**

```text
Crea una nota de cierre de [PROYECTO] con: qué se hizo, decisiones clave, lecciones aprendidas y pendientes. Usa solo lo que hay en el repositorio y cita los archivos.
```

**Si Claude responde mal:** casi siempre falta información o se guardó demasiado ruido. Añade o limpia, no cambies de herramienta.

**Siguiente nivel (opcional):** lo que has montado es el nivel 1, notas en texto plano. Existe un nivel 2, con base de datos y búsqueda más potente.

> El valor está en el hábito, no en la herramienta.

## Si te atascas

| Problema | Qué hacer |
|---|---|
| No puedes usar Claude Code (sin plan de pago) | Trabaja en pareja con otra persona y retoma en casa |
| Instalación bloqueada por tu empresa | Trabaja en pareja y retoma en casa |
| Conector de correo o calendario bloqueado | Plan B: pega o exporta el contenido |
| GitHub Desktop no hace push | Pide ayuda a un facilitador |
| No quieres usar datos reales | Pide a Claude el contenido de ejemplo ficticio |
| Publicaste el repositorio como público | En github.com: Settings → Danger Zone → Change visibility → Private |
| Tu memoria de Claude está vacía | Claude te entrevistará directamente en el Bloque 2A |
| La opción de GitHub no aparece en el Proyecto | Sube a mano los `.md` clave o termínalo en casa |
| Claude "inventa" al responder | Recuérdale la regla 1 de `CLAUDE.md`: solo lo que hay en el repositorio |
